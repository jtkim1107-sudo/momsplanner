# 소행성 육아플래너 🌟

임신 준비(프리맘)부터 36개월까지 **9개 구간 체크리스트** + **선배맘 판정 데이터**로
"무엇을, 언제, 살지 말지"를 알려주는 육아 플래너 프로토타입.

## 실행

빌드·서버 없이 정적 파일만으로 동작합니다.

```bash
# 아무 정적 서버로 열기 (또는 index.html 더블클릭)
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages에 그대로 배포 가능합니다 (Settings → Pages → 브랜치 선택).

## 핵심 기능

- **월령별 국민템 = 준비물 리스트의 하나** — 신생아·3~6개월·6~12개월·
  12~24개월·24~36개월이 준비물 칩으로 통합. 각 월령 상단에 🏆 국민템
  모아보기 카드(칩 탭 시 해당 아이템으로 점프)
- **결론 5단계** — 항목마다 의견을 집계해 한 줄 결론 칩 표시:
  **무조건 사세요** · **하나만 사보세요**(의견 갈림) · **무조건 당근하세요**
  (중고가 이득) · **장롱템, 패스하세요** · **절대 사지 마세요**.
  판정 30명 미만이면 순위 비공개(신뢰 게이트)
- **브랜드 순위** — 브랜드별 재구매율 순위 (가상 브랜드)
- **선배맘 한마디** — 항목별 경험담 댓글 (작성 시 localStorage 저장)
- **논쟁템** — 주 1개 찬반 투표 (가위파 vs 줄파)
- **지역혜택** — 전국 공통 혜택 + 시도별 확인 가이드 (금액 대신 확인처 안내 원칙)
- **검색** — 전 구간 아이템 검색 후 해당 위치로 점프
- **체크 진행률** — localStorage 저장, 구간 완료 시 보상 모달
- **⭐ 별똥별** — 데이터가 되는 활동에 포인트 적립: 체크 +5 ·
  "다시 산다면?" 1탭 판정 +10 · **"뭘로 샀어요?" 구매 기록 +15**
  (체크한 항목에만 노출 — 산 사람만 판정/기록. 그 항목의 유명 브랜드를
  칩으로 제시하고 없으면 직접 입력 → 표기 통일로 순위 집계 가능) · 한마디 +20 · 제보 +20 ·
  논쟁 투표 +30 · 구간 완료 +500. 내 구매 기록은 그 항목의 선배맘 의견
  목록에 "(나)"로 함께 표시되고 브랜드 순위의 원천이 됨.
  헤더 지갑에서 잔액·적립 내역 확인
- **살 것 / 당근으로 / 패스 플랜** — 준비물 모든 항목에 3버튼 선택.
  패스한 항목은 흐림 처리, 리스트의 전 항목을 다 정하면 리스트당 ⭐300.
- **📋 내 목록 (플랜 취합)** — 헤더 버튼 하나로 살 것/당근으로/패스/준비
  완료를 섹션별로 한눈에. 항목마다 출처 리스트 태그와 구매 기록 표시
- **단일 칩 네비게이션** — 출산·조리원·신생아·이유식·어린이집·월령별(3~36개월)
  리스트를 상단 칩 한 줄로 전환 (하단 미사용)
- **🏨 조리원 · 🏫 어린이집 · 🍽️ 이유식 리스트** — 출산준비물과 같은 엔진(체크·사요마요
  결론·브랜드칩·별똥별)을 재사용. 축이 각각 '입소 시즌' '이유식 시작'인
  별도 리스트
- **🛒 준비물 탭 (기본 화면)** — 맘카페에서 공유되는 실제 준비물 자료
  4종(공유 시트 · 선배맘 A/B 실사용 리스트 · 호호마더 미니멀 리스트)을
  병합한 10개 카테고리 100개 항목. **표준 리스트(공통 필수 52개) ↔
  내 리스트 토글** — 표준은 미니멀 필수 + 공통 필수만 추린 기준표,
  취향템은 카테고리별 "선택템 더 보기"로 접힘. 내 리스트에는 체크했거나
  살 것·당근으로 정한 항목만 모여 표준과 비교 가능. 플랜 완성(⭐300)도
  표준 구성 기준 (준비여부 · 구매수량 · 📦 필요 개수 · 🏷️ 참고 브랜드 ·
  💰 핫딜가 · 🥕 당근 추천). 같은 항목에 여러 선배맘의 의견이 나란히 표시 —
  👍추천/😐쏘쏘/👎비추 판정 · 실구매가 · 구매 경로(당근/쿠팡/선물/물려받음)
- **구간 ↔ 준비물 연동** — 같은 물건(카시트, 젖병, 유모차 등 18개)은 두
  목록이 체크 상태를 공유하고, 구간 아이템 상세에 시트 정보(개수·브랜드·
  가격·경험담)가 함께 표시. 시트의 🔗 배지를 누르면 해당 구간 아이템으로 점프

## 빅데이터 시뮬레이션 (`js/bigdata.js`)

실서비스에서 서버 집계 API가 내려줄 데이터를 클라이언트에서 재현합니다.

- 아이템 id를 시드로 쓰는 **고정 난수(mulberry32)** → 새로고침해도 수치 동일
- 전 구간 구매템 51개에 판정 140~3,000명, 총 **판정 7.7만 건 / 선배맘 약 8천 명** 규모
- 카테고리별 가상 브랜드 풀에서 3~5개 브랜드 순위 생성 (실제 상표와 무관)
- 항목당 0~4개 선배맘 댓글 생성 (총 300여 개)
- 일부 항목은 의도적으로 "판정 모으는 중" 상태 유지 → 30명 신뢰 게이트 UX 시연
- 실서비스 전환 시 이 파일을 서버 응답으로 교체하면 됨

> ⚠️ 판정 수치·브랜드·댓글은 전부 시뮬레이션 데이터입니다. 화면 상단에도 명시됩니다.
